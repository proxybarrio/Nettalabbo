# Roadmap and open work

This is an **aspirational list, not a release schedule or a promise of compatibility**.

## Reliability and usability

- Validate every major tool on real supported Ubuntu installations, including dependency resolution and upgrades.
- Improve timeouts, progress indication, cancellation and connection cleanup throughout the interface.
- Improve SSH and Telnet terminal rendering, interaction and session management.
- Extend browser-style navigation and link detection to more alternative-network response formats.
- Review historical server entries periodically and label unavailable or unconfirmed services.

## Protocol work

- More complete support and interoperability tests for Gemini, Gopher, Spartan, Nex and other alternative protocols.
- Investigate a verified interoperable specification for Terse before attempting implementation.
- Expand experimental Titan, Scorpion and Molerat features only with confirmed protocol details and explicit user consent for state-changing requests.

## Distribution and documentation

- Verify package metadata in graphical installers on supported Xubuntu releases; not all local installers display icon or licence metadata consistently.
- Publish source and release files under the Proxybarrio GitHub project when available.
- Establish a consistent release and regression test workflow.
