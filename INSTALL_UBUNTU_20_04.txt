NETTALABBO 0.5.0  |  Xubuntu 20.04 / Ubuntu Focal Fossa

FIXED: Python 3.8 compatibility (the prior package incorrectly required 3.10).
FIXED: requires the Ubuntu 'telnet' package, not a version-specific client.
Preserved: all dependencies mandatory; installation in a single APT operation.
Desktop icon: installed in hicolor icon themes, pixmaps, and shown inside About.

From your Downloads folder:

    cd ~/Downloads
    sudo apt update
    sudo apt install ./nettalabbo_0.5.0-1_all.deb

After installation:

    nettalabbo

If APT reports another unavailable dependency, copy its full output.

SOFTWARE INSTALLER NOTE: a generic gear and 'Proprietary' text can still
appear before installation in the Ubuntu 20.04 graphical software centre.
This is an installer preview limitation; the icons and MIT license metadata
are embedded in the .deb and should be discoverable after installation.

NEW: DNS utility dnsutils is installed automatically.
Mail Inspector and experimental Titan/Scorpion/Molerat tools included.
