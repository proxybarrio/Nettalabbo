# Nettalabbo 0.5.3, experimental source release

**Network Laboratory app for Xubuntu and other Ubuntu systems**

This is an early, experimental release of Nettalabbo, developed by Proxybarrio with AI assistance and licensed under MIT. It combines classic network diagnostics, mail/domain inspection, SSH and Telnet tools, and experimental clients for historical and alternative network protocols.

**Highlights:** click-through Gopher and Gemini navigation, permanently underlined hyperlinks and link detection in text, Back/Forward/Home/Stop, Rendered/Raw response views and classic diagnostic tools.

**Cautions:** the application is under active testing, may contain bugs and security vulnerabilities, and is not a full terminal emulator. SMTP recipient acceptance does not prove mailbox existence. Only scan or interrogate systems you are authorised to test. Never enter passwords over Telnet.

**History:** independently developed as an affectionate tribute to the original NetLab95 utility by Alexander Danileiko, with no affiliation, endorsement, use of the original source code or rights in the historical software.
