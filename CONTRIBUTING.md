# Contributing to Nettalabbo

Nettalabbo is an experimental, independent open source project by Proxybarrio, built with AI-assisted development. Feedback and improvements are welcome.

## Bug reports

Please use the GitHub issue tracker **once the public project is available**. Include:

1. Nettalabbo version and Debian revision (for example, `0.5.3-2`).
2. Xubuntu / Ubuntu version and desktop environment.
3. Which tool or protocol was used, including the relevant host and port if appropriate.
4. Steps to reproduce the problem and the expected versus observed result.
5. Relevant messages or logs, after redacting private information.

An issue template is included in `.github/ISSUE_TEMPLATE/bug_report.md`.

## Suggestions and changes

Describe the use case, not just the proposed interface change. For new protocol support, link to a trustworthy public specification and identify what is actually implemented and tested. Keep modern usability and user control in mind: no unexplained background connections, no automatic credentials, and clear Stop / Disconnect behaviour.

## Safety and privacy

Do not post passwords, private keys, session cookies, personal mailbox addresses or unrelated third-party data in public issues. Do not scan systems without authorization. Report security-sensitive issues cautiously; public vulnerability details should be withheld until a private contact route is available.

## Code and licensing

Original contributions should be compatible with the project's MIT licence. Do not submit copied resources or source code from the historic NetLab/NetLab95 program or other proprietary projects. Keep interface and documentation in English and the official subtitle unchanged.
